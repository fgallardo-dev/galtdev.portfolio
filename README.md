## About

Personal portfolio with an editorial look — Bodoni Moda headlines, floating tech cubes, and Kobi the koala. Every piece is built with three non-negotiables:

> **Semantics first · Accessibility always · Maximum performance**

No UI frameworks, no client-side bloat: static HTML generated by Astro, a few lines of vanilla JavaScript where interaction genuinely needs it.

## Features

- 🌍 **Real i18n routes** — `/` (Spanish) and `/en/` (English) with `hreflang`, canonical URLs, and full Open Graph metadata
- 🧭 **Semantic, accessible navigation** — real links, `aria-current` state, mobile menu driven by `aria-expanded` + CSS `:has()`
- 🎨 **Responsive hero** — fluid type with `clamp()`, a shared *stage* container so the koala and its pedestal scale in lockstep
- 🔍 **Project filter** — native `<select>` filtering cards through `data-*` attributes, with an `aria-live` empty state
- 🗂️ **Data-driven content** — projects and technologies live in typed data files, not in markup

## Tech stack

| Choice | Why |
|--------|-----|
| [Astro 7](https://astro.build) | Static output, zero JS by default — performance is the goal |
| TypeScript (strict) | Typed data models and honest interfaces |
| Tailwind CSS v4 | Design tokens via `@theme` in CSS, no config file |
| Vanilla JS | Two small scripts: mobile menu & project filter — nothing more |

## Structure

```
portfolioGaltdev/
├── public/            # static assets (favicon, logo, Kobi)
└── src/
    ├── components/    # Nav · Hero · Projects
    ├── data/          # typed sources: projects.ts, techs.ts
    ├── i18n/          # ES/EN translations
    ├── layouts/       # base layout: SEO, hreflang, fonts
    ├── pages/         # / (es) and /en/ routes
    └── styles/        # Tailwind v4 theme tokens
```

## Getting started

```bash
cd portfolioGaltdev
npm install
npm run dev      # → http://localhost:4321
```

| Script | Action |
|--------|--------|
| `npm run dev` | Dev server with hot reload |
| `npm run build` | Production build to `dist/` |
| `npm run preview` | Serve the production build locally |
